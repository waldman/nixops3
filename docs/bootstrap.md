# Bootstrap

## Machine identity

Each machine has two identifiers:

| Identifier | Source | Survives reinstall | Purpose |
|------------|--------|--------------------|---------|
| `hostname` | `hostname --fqdn` | Yes (set in NixOS config) | S3 path lookup, DynamoDB PK |
| `machine_id` | `/etc/machine-id` | No | DynamoDB deduplication |

`/etc/machine-id` is generated by systemd on first boot and persists across reboots. It changes on OS reinstall. This is acceptable — `hostname` is the durable identity.

## First boot sequence

On first start the daemon has no `last-hash` (tmpfs, cleared on reboot). It applies immediately without sleeping:

1. Systemd starts `nixops3d.service`
2. Daemon reads `/etc/nixops3/nixops3.toml`
3. No `last-hash` → applies immediately (no initial sleep)
4. Downloads config tree from S3
5. Fetches secrets from AWS Secrets Manager
6. Generates `/var/lib/nixops3/current/configuration.nix`
7. Runs `nixos-rebuild switch`
8. On success: writes `last-hash`, writes DynamoDB heartbeat
9. Enters normal poll loop with jitter sleep

## Option A — Golden ISO (bare metal)

A Golden ISO is a NixOS installer image with the daemon and config pre-embedded. It performs an unattended installation and boots into a fully configured machine.

### What the ISO embeds

- The `nixops3d` binary
- `/etc/nixops3/nixops3.toml` with the bucket, region, role, and credentials
- A minimal `configuration.nix` that enables the daemon service

The ISO does **not** embed a `machine_id`. Identity is established on first boot by systemd.

### Auto-install script

The ISO includes a systemd `oneshot` service that runs at boot:

```
1. Wait for network (systemd-networkd-wait-online)
2. Detect primary disk (largest block device, or kernel cmdline nixops3.disk=)
3. Partition: 512 MB ESP + remainder root (ext4)
4. Mount at /mnt
5. nixos-generate-config --root /mnt
6. Copy /etc/nixops3/nixops3.toml to /mnt/etc/nixops3/
7. Copy base configuration.nix to /mnt/etc/nixos/
8. nixos-install --no-root-passwd
9. Print IP address to console/serial
10. Reboot
```

After reboot, the installed system runs the daemon, which fetches and applies the full configuration from S3 on first poll.

### Security note

The Golden ISO contains AWS credentials. Treat ISO files as sensitive artifacts:
- Do not upload to public storage.
- Rotate the embedded credentials after provisioning.
- For EC2, use IAM instance roles instead — omit the `[aws]` section from `nixops3.toml`.

### Role-specific ISOs

For v1, the role is hardcoded in the ISO. One ISO per role is acceptable at small fleet sizes.

Future: pass `nixops3.role=home/production/webserver` on the kernel command line to parameterise a single generic ISO.

## Option B — cloud-init (VMs)

For VMs, use a base NixOS image with cloud-init. The `write_files` directive installs the config file; the daemon handles everything else on first boot.

```yaml
#cloud-config

write_files:
  - path: /etc/nixops3/nixops3.toml
    permissions: '0600'
    owner: root:root
    content: |
      bucket = "nixops3-myhomelab"
      region = "us-east-1"
      role   = "home/production/webserver"

      [inventory]
      enabled = true
      table   = "nixops3-inventory"

runcmd:
  - mkdir -p /etc/nixops3
  - chmod 700 /etc/nixops3
  - systemctl enable --now nixops3d
```

For EC2, omit the `[aws]` section and attach an IAM instance role with S3 read access.

## NixOS module

To include the daemon in a NixOS configuration, add a system service. A minimal NixOS module:

```nix
{ pkgs, ... }:
let
  nixops3d = pkgs.callPackage ./nixops3d.nix {};
in
{
  systemd.services.nixops3d = {
    description = "NixOpS3 configuration daemon";
    after = [ "network-online.target" ];
    wants = [ "network-online.target" ];
    wantedBy = [ "multi-user.target" ];

    # nixos-rebuild and nixos-generate-config live in the system PATH, which
    # systemd does not inherit. Extend it explicitly.
    environment = {
      PATH = "/run/current-system/sw/bin:/run/wrappers/bin";
    };

    serviceConfig = {
      Type = "simple";
      ExecStart = "${nixops3d}/bin/nixops3d";
      Restart = "on-failure";
      RestartSec = "30s";
    };
  };

  systemd.tmpfiles.rules = [
    "d /run/nixops3         0700 root root -"
    "d /run/nixops3/secrets 0700 root root -"
    "d /var/lib/nixops3     0755 root root -"
  ];
}
```
